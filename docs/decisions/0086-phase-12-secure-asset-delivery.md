## 1. Context

**FACT (DR 0081 §2):** Cloudflare R2 is the sole internal object storage
provider. `file_key` (per DR 0054) is the canonical reference to a stored
asset. R2 credentials are server-side only; they are never surfaced to clients
or embedded in client-accessible configuration.

**FACT (DR 0081 §5):** Signed URL generation for content delivery was
explicitly deferred from Phase 11. The deferral condition was: "until the
delivery API route is defined."

**FACT (DR 0082 §3.4):** Phase 11 established that Higgsfield CDN URLs are not
persisted as canonical asset storage. `assets.content_url = null` after
materialization. The R2 `file_key` is the canonical reference. This means
asset content is only accessible through a server-generated signed URL.

**FACT (app/api/assets/[assetId]/url/route.ts, Phase 12 implementation):**
The Phase 12 implementation defines `GET /api/assets/[assetId]/url` as the
single authorized path for obtaining a time-limited asset download URL.
This is the only route that generates signed URLs for asset content.

**FACT (Phase 12 implementation):** `SIGNED_URL_EXPIRY_SECONDS = 3600`
(one hour). This is the V1 expiry for all signed URLs generated by this route.

## 2. Decision

### 2.1 Route: GET /api/assets/[assetId]/url

**APPROVED:** The single authorized path for asset download URL generation is:

```
GET /api/assets/[assetId]/url
```

This route is implemented in `app/api/assets/[assetId]/url/route.ts`.

### 2.2 Four-Step Authorization and Delivery Flow

**APPROVED:** The route handler performs the following steps in order:

1. **Authentication:** Call `auth()`. If no session or `session.user.id` is
   absent, return HTTP 401.

2. **Tenant membership:** Derive `organizationId` from `session.user.organizationId`.
   If absent, return HTTP 403. Call `getMembership(userId, organizationId)`.
   If membership is not confirmed, return HTTP 403.

3. **Tenant-isolated asset lookup:** Query `production.assets` where
   `id = :assetId AND organization_id = :organizationId`. If no row is
   returned, return HTTP 404. If the asset row has no `file_key`, return
   HTTP 404 (asset content not yet materialized).

4. **Signed URL generation:** Call `generateSignedUrl(file_key, 3600)`.
   Return HTTP 200 with `{ url, expiresAt }`. If `generateSignedUrl` throws,
   return HTTP 500.

No step may be skipped or reordered.

### 2.3 Response Shape

**APPROVED:** On success (HTTP 200), the response body is:

```json
{
  "url": "<presigned R2 URL>",
  "expiresAt": "<ISO 8601 datetime approximately 3600s in the future>"
}
```

The `url` is a presigned R2 URL. It is not a Higgsfield CDN URL, a static
public URL, or any other URL shape (DR 0081 §2, DR 0082 §3.4).

### 2.4 Signed URL Expiry

**APPROVED:** `SIGNED_URL_EXPIRY_SECONDS = 3600` (one hour). This constant
is passed to `generateSignedUrl` as the `expiry` argument. Callers must not
cache the URL beyond its `expiresAt` time.

### 2.5 R2 Credentials Boundary

**APPROVED:** R2 credentials (access key ID, secret access key, bucket name,
account ID) are server-side environment variables only. They are never surfaced
in any client response, any publicly accessible configuration, or any
`NEXT_PUBLIC_` environment variable. The `generateSignedUrl` function is the
sole authorized path for consuming R2 credentials to generate a URL.

### 2.6 Error Response Mapping

**APPROVED:**

| Condition                                  | HTTP status |
|--------------------------------------------|-------------|
| No session or no `user.id`                 | 401         |
| No `organizationId` or no membership       | 403         |
| Invalid `assetId` format                   | 400         |
| Asset not found or no `file_key`           | 404         |
| `generateSignedUrl` throws                 | 500         |
| Success                                    | 200         |

### 2.7 Tenant Isolation

**APPROVED:** The asset lookup in §2.2 step 3 must always include
`organization_id = :organizationId` where `:organizationId` comes from
`session.user.organizationId` (server-side JWT). No `organization_id` from
a client request body or query parameter is used.

### 2.8 No Persistent URL Storage

**APPROVED:** Signed URLs are generated on demand and are not persisted to
the database, cache, or any storage layer. Each request generates a fresh URL.
The `expiresAt` in the response is informational for the caller.

## 3. Explicitly Prohibited Assumptions

- Do not assume Higgsfield CDN URLs may be returned as the `url` field —
  prohibited (§2.3, DR 0082 §3.4).
- Do not assume R2 credentials may be surfaced to clients or in
  `NEXT_PUBLIC_` variables — prohibited (§2.5).
- Do not skip the membership check (§2.2 step 2) — required for all callers.
- Do not assume `organization_id` may come from a client request parameter —
  server-side JWT only (§2.7).
- Do not cache signed URLs beyond their `expiresAt` — they are time-limited
  (§2.4).
- Do not persist signed URLs to the database — on-demand generation only (§2.8).
- Do not assume this record modifies Decision Records 0001–0082 — it does not.
